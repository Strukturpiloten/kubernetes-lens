# KubernetesLens status

KubernetesLens is an unpublished repository bootstrap. Native parsing, model processing,
validation, editing and rendering are future work. No Kubernetes version or deployment
workflow is currently supported. Repository validation results prove tooling contracts only.

The [Kubernetes 1.20–1.37 compatibility specification](../compatibility/README.md) freezes expected
behavior for 35 kinds and named tool profiles. Its source/specification checks pass independently
of future native execution; it does not change the empty supported-version list.
