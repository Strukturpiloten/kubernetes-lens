# KubernetesLens status

KubernetesLens is an unpublished offline native-format foundation. It parses bounded YAML/JSON,
retains private source evidence and Lists, computes identities and supplied-only references,
supports explicit edits and target checks, and generates deterministic private native artifacts.
Explicit bounded regular-file/directory acquisition is available on Linux.

Eight workload kinds have typed codecs, native validation and generation, including both admitted
CronJob APIs. Shared helpers, bounded authoring, supplied facts and exact observation roles are
available; see [workload limits](../workloads.md). The other 27 built-in kinds remain
preservation-only. Preservation requires explicit output policy and produces structured findings.
No Kubernetes minor, renderer, admission/controller/runtime behavior, deployment workflow, or live
cluster client is claimed.

The [Kubernetes 1.20–1.37 specification](../compatibility/README.md) remains source-backed expected
behavior with pending native evidence. Foundation tests prove their scoped library behavior only;
they do not change its empty supported-version list or mark compatibility cells passed.
