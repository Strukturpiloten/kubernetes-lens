# ADR0084: Private first explicit parent failure after node enrollment

Status: Accepted bounded source contract; independent final source review, complete
validation and separately adopted native qualification pending (#62).

## Context

V22n remains failed-retired with create0/delete0, source Deployment not reached,
V7 diagnostic fields null and the ordinary node-inspect role present. Enrollment
followed the n inspect and j predicate, after which V7 cleared its active site.
Existing aggregate counters cannot uniquely locate the later failure. Offline
closed checks of the retained role repeated existing host semantic guarantees;
they establish no cached-inventory, live-process, helper or downstream cause.
No additional captured-body analysis or native retry is part of this change.

## Decision

Adopt explicit V8 with exactly the V7 member set. Reuse the existing unexported
postlog_site and immutable first-parent-fail postlog_failure. After successful
remember node-inspect, enter a instead of clearing the site, then assign only these
closed groups at the existing statement boundaries:

| Code  | Existing action or guard group                                                         |
| ----- | -------------------------------------------------------------------------------------- |
| pl2.a | Cgroup-equality jq action and parent helper guards                                     |
| pl2.b | PID extraction and decimal/range guards                                                |
| pl2.c | Cached inventory start lookup and decimal guard                                        |
| pl2.d | First proc stat read and PID/start identity guards                                     |
| pl2.g | Proc cgroup read and equality guards                                                   |
| pl2.h | Second proc stat read and start identity guard                                         |
| pl2.k | Broad downstream config/version/readiness/namespace/fixture/dry-run actions and guards |

The k group is intentionally broad; it never identifies a specific kubectl cause.
Only an actual existing explicit parent fail records the active group. Retain the
BASH_SUBSHELL==0, admitted execution intent, work mode and empty-first-code guard.
Entry, skipped actions, child failure alone, ERR and signals supply no code. A
parent failing after a child records its own active group without child values.
The first code remains immutable across later groups and cleanup. Finish still
captures incoming $? as its first statement, then clears the site before trap
changes, pace closure, diagnosis, cleanup and evidence.

Under the unchanged LC_ALL=C, compress the original recorder alternatives to
[rifnje] and admit exactly [a-dghk] for pl2. The emitter admits the corresponding
exact pl1 and pl2 sets. No initialization state, command, query, process, observer,
wait, retry or new raw value is introduced. Preserve every original action, guard,
operation count, credit, cap, deadline, resource limit and cleanup order.

## Strict codec and history

Non-null pl2 is V8-only and requires failed, actual integer create0, source
Deployment not-reached, the existing genuine positive seven-role log proof and an
ordinary node-inspect catalogue member. Original catalogue integrity, raw-byte
bounds and node identity/image/state/args/network/cgroup/PID checks still apply.

their no-node-inspect requirement stay unchanged, including native status only at
pl1.n and resource reason only at pl1.r. Null remains absence of an admitted first
explicit fail, never proof of success or an inferred cause.

inserted defaults or fallback. A separate strict V8-to-frozen C6 V7 inverse
(65270 bytes, c6b771cfbe64491b5dc39bc597574b8b0134cce388c37fd3cb7c076f2f7a514d)
precedes all unchanged earlier constants and inverses. The compact-inspect contract

the earlier post-node active-site clear. All 550 registered predecessor test IDs

Historical compact-only comparisons explicitly retain their frozen V7 domain.

## Envelope, privacy and evidence limits

The reviewed receiver is exactly 65408 bytes, SHA-256
`d265f8834fdca00d79f9a4fdd487f3e5574813eeb5337cf10ece9dd5740adecb`.
It adds exactly 138 bytes over C6 V7. The 65408-byte integration envelope is
enforced; 65536 remains the hard cap. Current enrollment binds only this source.
No tool, package, image, pin or operational definition changes, so existing
Renovate ownership and integrity records remain unchanged.

Codes remain private in the existing bounded wire and durable receipt. Public
output gains no attribution, code, native value or raw body. Original outer error,
delete-failure, budget and whole-target retirement semantics remain independent.
Pure controls exercise the actual finite Bash clauses, original fixed-DATA action
traces, each group, child/parent/ERR/signal/cleanup paths, strict codec refusal,
history tamper seals, private durability and public redaction. Runtime helpers and
all apparent proc reads are replaced before any projected statement runs; no
Podman, kubectl or actual proc query is allowed. These source checks establish no
native cause, readiness, runtime conformance or retry authority. The primary owns
final source review, complete validation and any separately adopted native work.
