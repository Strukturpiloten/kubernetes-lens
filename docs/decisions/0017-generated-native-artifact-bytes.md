# ADR 0017: Generated native artifact bytes and original associations

Status: Accepted

Partly supersedes ADR 0012's generated-project ordering, layout and serialization behavior. Its
explicit renderer selection, protected access, provenance limits and pending native conformance
remain accepted. Refines ADRs 0006 and 0008 without changing their cumulative ceilings.

## Decision

Generated Helm and Kustomize artifacts emit native roots in immutable source argument order, then
original document order, then depth-first nested List item-array order. Reordering the mutable
ResourceSet document slice does not change that order. Ordinary public native `generate` retains
its existing effective-identity ordering and serialization; the generated-project profile does not
change that API. Lists still require explicit Flatten. Every wrapper, including empty Lists, retains
native target, opaque, protected, tag and observation checks; removed wrapper fields retain structured
source-bound findings. Caller policies and observation intent are honored without implicit changes.

`ArtifactTree::emitted_resources` exposes library-created `EmittedResourceAssociation` entries with
a zero-based global ordinal, original input-local ResourceId, immutable SourceRef and optional full
CollectionPath. Association comes from the same successful native root projection, includes static
CRDs, and is empty for zero roots. It never substitutes a reparsed ID or derives an association from
identity, document position, output name or ordinal. Coordinates contain no protected value payload;
artifact bytes still require explicit artifact access. These entries supply no native admission,
external origin/projection seal, file digest, harness witness or runtime authority.

The generated-project JSON profile serializes UTF-8 strings with JSON control escapes, preserves
literal Unicode (including U+2028/U+2029), sorts object keys by UTF-8 bytes and retains array order.
Raw and protected numeric lexemes retain sign, fraction and exponent spelling without floating-point
conversion. Typed integers remain shortest decimal. Go interpreted string arguments use the same
escapes plus DEL as `\u007f`. Static template keys and scalars are closed `print` expressions around
quoted JSON tokens. Selected values use closed `toJson (index .Values <quoted-name>)` expressions.
Nonempty template objects have one space inside each brace; empty objects remain `{}`. No supplied
string becomes template code, and no `tpl` operation is introduced.

Helm emits Chart.yaml, values.yaml, values.schema.json and one templates/resources.yaml. Static
native CRDs use crds/<six-digit-global-ordinal>.yaml, retaining their position among all emitted
roots. Custom kinds named CustomResourceDefinition do not acquire native CRD classification.
Non-CRD templates preserve emitted order. Zero-root and CRD-only templates contain the fixed zero-root
comment. Mapping files contain compact JSON plus LF; native streams prefix each mapping with `---`
and LF. Values/defaults and schema properties/required names are sorted. Defaults are existing,
non-null supplied leaves only. The Draft 7 schema rejects additional keys and preserves the finite
64-field replicas/image/quantity interface and its integer/string bounds.

Kustomize emits a reusable base and only requested nonempty overlays. An empty base contains only
base/kustomization.yaml with an empty resources array. Variations bind original ResourceIds, exact
admitted workload GVKs and unique existing ordinary-container names. Missing, null, ambiguous,
unsupported and duplicate selected leaves refuse, including repeated equal replacements. All edits
for each resource are grouped and the complete modified native tree is validated under the original
policies. One minimal strategic merge patch per selected resource preserves emitted order; selected
containers preserve original array order and use native names as merge keys. Unselected base
siblings remain supplied data. No whole-array replacement or `$patch` directive is introduced.

New traversal stacks, key sorting, association paths, grouping buffers, strings and output copies
preflight charges in the original sticky processing session. Initial projection, generated reparse,
field edits, complete overlay validation and serialization share that session and inherited parser
ceilings. Exhaustion cannot yield a successful artifact. No dependency or tool pin changes are needed.

## Migration and evidence

This intentionally changes unpublished generated bytes and filenames. Replace per-root
`templates/0000.yaml` consumers with the templates/resources.yaml stream, and four-digit CRD paths
with six-digit global ordinals. Mapping-file readers must accept JSON plus LF without a YAML document
marker; native resource and patch streams retain markers. Template consumers must recognize indexed
`toJson` expressions rather than dotted values access. Use emitted associations to join original
source coordinates; mutable document positions and generated IDs are not provenance.

Repository-authored literal, negative, association, observation and cumulative-budget tests establish
local API behavior. They do not establish official Helm/Kustomize execution, native admission,
full-corpus semantic seals or runtime conformance. Those obligations remain independently pending.
