# ADR0081: Private first existing post-log resource reason

Status: Accepted source contract; independent final source review, complete validation
and separately adopted native qualification pending (#62).

## Context

V20n-v2 remains failed-retired under v6: pl1.r, native snapshot null, create0/delete0,
source Deployment not reached. The packet has no current resource predicate/value or
reason member. Resource_check and inventory already supply30 fixed fail labels; some
command/helper failures supply no label. The existing prerequisite-only reason frame
is not emitted in admitted execution. Preserve an already-supplied fixed reason
without making a new observation, inferring a cause or relabeling the spent result.

## Decision

Explicit kubernetes-lens-owned-rootful-result-v7 retains v6 fields and adds required
PRIVATE postlog_reason. It is null except for pl1.r, which requires a string from
the exact30 existing resource_check/inventory labels plus fixed unlabelled. The
closed labels cover pid-max, nr-open format/range, namespace, mount variants, memory,
block, mapper, filesystem and existing inv-* groups; the codec/source enumerate each
exact string and admit no wildcard. Unlabelled means no admitted fixed reason, not
a classified tool/clock/credit cause. Missing, empty and arbitrary arguments map to
that literal; no arbitrary argument or guest value is serialized.

Reset and unexport one private JSON scalar at startup. Only inside the EXISTING FIRST
explicit admitted parent fail block and only active site r, select the closed label
and encode it with builtin printf; otherwise encode literal unlabelled. Existing
BASH_SUBSHELL0, execution/admission/work and first-code guards remain unchanged.
Do not reuse previous args, add branch observers, or let site entry record a reason.
Child/subshell fail cannot set parent state. A later actual parent fail records the
parent's own existing label, which may group multiple conditions. ERR/signals without
parent fail stay null. No new arguments, query, process, observer, read, raw capture,
catalogue role, credit, native command or retry is introduced.

Finish MUST keep its original FIRST status capture, then clear active site before
traps/pace/diagnosis/cleanup/evidence. Preserve the first scalar immutably: cleanup
cannot fill null or replace it. Non-null shares pl1.r's failed/create strict integer0,
not-reached, genuine positive seven-role log proof and no-node-inspect scope. V6 native
snapshots remain null for r and retain their exact previous semantics for n. Other
sites, positive results and no explicit parent fail require null. Validate strict
scalar types, membership, required keys and exact version dispatch. Never synthesize
this field into V1–V6 objects or change their evidence/source meanings.

Add one sealed V7-to-frozen64608-byte0eeaf51 V6 inverse before the unchanged earlier
seams and constants/deltas. Current enrollment changes only to current canonical bytes.
Preserve all531 prior test IDs and314 literal prerequisite patterns. Old future-version
negative bodies remain unchanged when missing new required fields still makes them
invalid; add explicit futureV8 refusal and genuine V7 controls.
